# 界面截图

将以下截图放入此目录替换 README 中的占位图：

| 文件名 | 内容 |
|--------|------|
| `main.png` | 主界面 — 终端 + 多标签 + SSH 连接状态 |
| `vps-dashboard.png` | VPS 作战看板 — 到期/流量/价格/状态 |

## 截取建议

- 使用 **1920×1080** 分辨率
- 关闭敏感信息（IP、hostname 可打码）
- 使用默认深色主题
- PNG 格式，压缩优化
